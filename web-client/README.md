# SFILE Web Interface

This applications allows the upload and the download of file to sign theses.
This is an interface between the sfile protocols

---

## Stack Technique

- React
- Vite
- TypeScript
- CSS / Tailwind
- Shadcn

---

### 1. Clone and install locally

```bash
git clone https://gitlab.ecole.ensicaen.fr/ple-meur/smp4.git
cd web-client
yarn install
yarn dev
```

### 2. Existing page

 - "/" (redirect to player page)
 - "/player"
 - "/login"
 - "/register"
 - "/profil" (require authentification )
